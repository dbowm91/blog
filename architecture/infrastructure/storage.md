# Storage (`app/storage.py`)

Storage abstraction for media files.

## Backends

| Backend | Environment | Purpose |
|---------|-------------|---------|
| Local | `STORAGE_BACKEND=local` (default) | Filesystem storage |
| S3 | `STORAGE_BACKEND=s3` | S3-compatible object storage |

## Local Storage

```python
class LocalStorageBackend(StorageBackend):
    def __init__(self, base_dir: str): ...

    def save(self, filename: str, data: bytes) -> str: ...
    def load(self, filename: str) -> Optional[bytes]: ...
    def delete(self, filename: str) -> bool: ...
    def exists(self, filename: str) -> bool: ...
    def url(self, filename: str) -> str: ...  # Returns /static/uploads/{filename}
    def list_files(self, prefix: str = "") -> list[str]: ...
    def path(self, filename: str) -> str: ...  # Local filesystem path
```

## S3 Storage

```python
class S3StorageBackend(StorageBackend):
    def __init__(
        self,
        bucket: str,
        region: str = "us-east-1",
        endpoint: str = "",
        access_key: str = "",
        secret_key: str = "",
        public_url: str = "",
    ): ...

    def save(self, filename: str, data: bytes) -> str: ...
    def load(self, filename: str) -> Optional[bytes]: ...
    def delete(self, filename: str) -> bool: ...
    def exists(self, filename: str) -> bool: ...
    def url(self, filename: str) -> str: ...  # Returns public URL
    def list_files(self, prefix: str = "") -> list[str]: ...
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `STORAGE_BACKEND` | `local` or `s3` |
| `S3_BUCKET` | S3 bucket name |
| `S3_REGION` | AWS region (default: us-east-1) |
| `S3_ENDPOINT` | S3-compatible endpoint (for MinIO, etc.) |
| `S3_ACCESS_KEY` | AWS access key |
| `S3_SECRET_KEY` | AWS secret key |
| `S3_PUBLIC_URL` | Custom CDN URL |

## Factory Function

```python
def get_storage_backend() -> StorageBackend:
    if STORAGE_BACKEND == "s3":
        return S3StorageBackend(...)
    return LocalStorageBackend(...)

_storage: Optional[StorageBackend] = None

def get_storage() -> StorageBackend:
    """Returns singleton storage instance."""
```

## Image Processing

### `upload_with_processing()`

```python
def upload_with_processing(
    filename: str,
    file_content: bytes,
    generate_variants: bool = True
) -> tuple[str, None] | tuple[None, str]:
```

Saves image and queues `generate_image_variants` Celery task.

### Responsive Variants

Generated by Celery task (`generate_image_variants`):
- `400_{basename}.webp`
- `800_{basename}.webp`
- `1200_{basename}.webp`
- Original format variants
